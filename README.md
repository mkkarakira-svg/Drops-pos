# Drops POS

Drops POS is the Android point-of-sale and inventory system for Drops Detergents.

## V1 scope
- Dashboard
- Point of sale / sales invoices
- Products and package sizes
- Inventory and stock movements
- Customers
- Suppliers
- Expenses
- Reports
- Production / manufacturing stock flow
- USD and LBP support

Development branch: `develop-pos-v1`.

The existing working APK build on main is kept untouched while V1 is developed and tested.
